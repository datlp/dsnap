Engineered for Speed and Simplicity

No Electron bloat. No .NET runtime required. Built from the ground up in native Win32 C++17.

📸

Freeze Desktop Snapshot

Instantly freezes the desktop into memory in under 2ms using CAPTUREBLT. Reliably captures right-click menus, system tray popups, flyouts, and tooltips without dismissing them.

🎙️

Native WASAPI Loopback Audio

Direct system audio capture via Core Audio APIs. Record crystal-clear sound from YouTube, Spotify, games, and meetings directly without Stereo Mix or virtual cable drivers.

🎬

Click-Through Border & Controls

Highlight border is invisible to the recorded MP4 video via WDA_EXCLUDEFROMCAPTURE. Floating toolbar provides live recording timer, instant Pause, Resume, and Cancel.

⚡

1-Click Auto FFmpeg Setup

Missing FFmpeg? dsnap automatically prompts and downloads portable FFmpeg from GitHub Releases CDN in the background using native tar.exe extraction with zero manual steps.

💾

True Zero-Footprint Portable Mode

Place a dsnap.ini file or start with --portable. All configurations and captures stay localized inside the folder with zero Windows Registry modifications. Perfect for USB drives.

🪶

Under 450 KB & Multi-Monitor DPI

Zero external DLL dependencies. Consumes ~8 MB idle RAM. Full Per-Monitor DPI Awareness V2 spanning multiple monitors with mixed DPI scaling (100% to 200%).

Global Shortcuts & Cheatsheet

Intercepted instantly via low-level keyboard hook without hotkey conflicts.

PrintScreen
Capture Screenshot — Freezes desktop, select region to save PNG and auto-copy to Clipboard (Ctrl+V).
Shift + PrintScreen
Record Screen — Select region to record MP4 video with floating control bar. Pressing again cleanly stops recording.
Escape
Cancel Selection — Instantly dismisses active freeze overlay or cancels selection without saving.
